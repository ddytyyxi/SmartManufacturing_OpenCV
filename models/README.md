## 📦 Models

이 폴더에는 학습된 YOLO 모델 파일들이 저장됩니다.

## 모델 파일

### `best.pt`
- **설명**: 검증 데이터셋에서 가장 높은 성능을 기록한 모델
- **용도**: 실제 추론(inference) 및 프로덕션 환경에서 사용
- **저장 시점**: 검증 mAP(mean Average Precision)가 최고치를 갱신할 때마다 자동 저장

### `last.pt`
- **설명**: 학습이 완료된 마지막 에포크의 모델
- **용도**: 학습 재개(resume training) 또는 추가 fine-tuning
- **저장 시점**: 매 에포크 종료 시 자동 저장
